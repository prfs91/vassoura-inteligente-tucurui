# Computação na Educação Básica: O Contexto de Tucuruí-PA e as Diretrizes da BNCC

Este repositório centraliza o ecossistema de dados, scripts de análise em Python e o levantamento bibliográfico que fundamentam o nosso artigo científico focado na aplicação do pensamento computacional e robótica sustentável na Amazônia.

## 📊 Fontes de Dados Utilizadas
O projeto manipula e cruza dados brutos obtidos de bases oficiais para diagnosticar o cenário regional:
* **IBGE (SIDRA/PNAD Contínua TIC):** Indicadores de conectividade residencial e funcionamento de rede móvel no Pará e Região Norte.
* **INEP (Censo Escolar):** Levantamento da infraestrutura tecnológica e presença de laboratórios de informática nas escolas de Tucuruí.
* **Indicadores Municipais:** Dados locais sobre a gestão e estrutura da rede pública de ensino.

## 📁 Estrutura do Repositório
O projeto adota as boas práticas de organização de Data Science:
* `data/raw/`: Bases de dados originais e inalteradas (IBGE, INEP, etc.).
* `data/processed/`: DataFrames limpos, tipados e unificados via Python.
* `notebooks/`: Jupyter Notebooks para exploração de dados e geração de gráficos.
* `src/`: Scripts Python (`.py`) de automação do pipeline de dados.
* `output/`: Gráficos (PNG/PDF) e tabelas (Markdown/CSV) gerados prontos para o artigo.
* `references/`: Artigos em PDF e materiais bibliográficos utilizados como fundamentação teórica.
